# CS439_Final-Project - Exercise Patterns and Health Metrics

This project looks at how exercise habits and health measurements are related to amount of calories burned. The objective is to clean the dataset, explore the data, and create simple visualizations to better understand workout patterns.

## What This Project Does

- Cleans and organizes exercise and health data
- Looks at variables like age, weight, BMI, heart rate, workout duration, exercise type, and intensity
- Creates charts to show trends in calories burned
- Uses Python for data analysis and visualization

## Tools Used

- Python
- JupyterLab
- pandas
- Matplotlib
- NumPy
- scikit-learn

## Main Findings

The analysis showed that calories burned depends on more than one factor. Workout duration, intensity, exercise type, heart rate, BMI, and weight can all play a role. Some workouts burned more calories on average, but no single variable explains everything by itself.

## Visualizations Included

- Calories burned distribution
- Average calories burned by exercise type
- Workout duration vs. calories burned
- Calories burned by exercise intensity
- Correlation matrix
- K-Means clustering with PCA

## Conclusion

This project helps turn raw exercise data into clear visual insights. It shows how Python can be used to explore health and fitness data and better understand patterns in workout behavior.
